# Hong Kong Transit Hub

做一個實時香港交通的app。底部bar包括首頁、巴士、地鐵、渡輪、天氣、特別交通消息，請使用icon作爲bar的設計。

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://hongkong-go-go.lovable.app
